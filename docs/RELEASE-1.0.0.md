Commeto helps you find and assess educational videos using traceable evidence.

Published by **biskootmonster** under the MIT license.

Included:
- Discovery, individual-video audits, and learning sequences.
- Four-tier evidence rubric with explicit missing-data handling.
- Verified timestamps and claim-source records.
- Optional offline JSON validation and scoring helper.
- Portable ChatGPT/Codex plugin package and GitHub marketplace.
- Privacy notice, support channel, examples, and automated tests.

Install:

```sh
codex plugin marketplace add efter-dash/commeto
codex plugin add commeto@commeto
```

Download `commeto-1.0.0.zip` for the plugin package; `SHA256SUMS` verifies its
integrity. The source archives also include development tools and examples.

Live research requires the host's available web tools. This is a skills-only
plugin with no paid backend or separate account. Normal host limits apply.

**OpenAI directory status:** not submitted or approved. GitHub distribution and
marketplace installation are available now.
