# Commeto privacy notice

Effective date: 27 October 2026. Publisher: **biskootmonster**.

Commeto 1.0 is a package of instructions, references, icons, and an optional
offline Python helper. It does not operate a server, register user accounts,
embed analytics, set tracking cookies, or transmit data to the publisher.

When you use Commeto inside ChatGPT or Codex, the host processes your messages,
files, and tool requests according to that service's terms, settings, and privacy
policy. Web searches and page retrievals may transmit search terms or URLs to the
host's search providers and the sites requested. Any additional service you choose
to connect has its own data practices.

The optional scoring helper reads the JSON file you specify. It does not make
network requests. If you specify an output path it saves the report there;
otherwise it prints the report. Those files remain in your execution environment
and can be deleted by you. The host may retain tool outputs in your conversation
according to its own settings.

No user research data is collected by a Commeto backend, so there is no
publisher-side research database or retention period. Saved local reports are
not automatically deleted.

If you post a public GitHub issue, GitHub processes your account details and
issue content and makes that content visible under its own settings and policies.
The publisher can read and respond to the issue. Issues may remain until removed
through GitHub's controls. Do not include secrets or sensitive personal data.

Support and privacy questions:
[Commeto Issues](https://github.com/efter-dash/commeto/issues).
If a future release introduces a hosted service or telemetry, this notice must be
updated before that behavior is released.
